## 1. 背景

Issue #9 (ボタンデザイン統一) の作業中に確認され、**同 Issue のスコープ外として明示的に見送った 2 件**を扱う。

### 1.1 課題 A: データソース一覧テーブルが横溢れする

`/connections` を実測した結果（ビューポート 1024px）:

| 対象 | 幅 |
|---|---|
| `main.container` | 1024px |
| `table` | **4301px** |
| `名前` 列 | 91px |
| `ドライバー` 列 | 275px |
| `URL (masked)` 列 | **3819px** |
| `Action` 列 | 117px（画面右外 約 3277px の位置） |

`document.documentElement.scrollWidth` も 4301px になり、**ページ全体が横スクロール**する。

原因は、マスク済み JDBC 接続文字列が

```
jdbc:bcart:AuthScheme=PersonalAccessToken;PersonalAccessToken=***;InitiateOAuth=OFF;OAuthSettingsLocation=%APPDATA%\CData\Bcart Data Provider\OAuthSettings.txt;BatchSize=0;...
```

のように改行機会のない 1 トークンで、`td` に `word-break` も `max-width` も指定がないため。
`table { width: 100% }` は auto レイアウトでは下限にしかならず、コンテンツ幅が優先されて容器を超える。

結果として **行内の「接続テスト」「編集」ボタンが画面外に出て押せない**。
Issue #9 でボタンのバリアントを揃えたにもかかわらず、この画面ではそのボタン自体が見えていない。

`ドライバー` 一覧 (`/drivers`) も `ファイル名` / `ドライバークラス` を `<code>` で出しており、
同じ構造の潜在的な溢れを持つ。

### 1.2 課題 B: データソース / ドライバー画面の英語表記

Issue #9 でボタンラベルのみ日本語化したため、**ボタンだけ日本語で見出し・列名・入力ラベルは英語**という
中間状態になっている。

```
現状の /connections
┌──────────────────────────────────────────────┐
│ JDBC Connections (5)      [+ 新しいデータソース接続] │ ← 見出しは英語、ボタンは日本語
├──────┬────────┬──────────────┬────────┤
│ Name │ Driver │ URL (masked) │ Action │        ← 列名は英語
├──────┼────────┼──────────────┼────────┤
│ Bart │ ...    │ ...          │ [接続テスト][編集] │ ← ボタンは日本語
```

一方、ヘッダーナビとヘルプ画面では既に日本語の呼称が確定している。

| パス | 確定している呼称 | 根拠 |
|---|---|---|
| `/` | ダッシュボード | `Layout.kt:53`, `HelpView.kt:121` |
| `/syncs` | 連携 | `Layout.kt:54`, `HelpView.kt:122` |
| `/connections` | データソース（個々のレコードは「データソース接続」） | `Layout.kt:55`, `HelpView.kt:123`, `HelpView.kt:62` |
| `/drivers` | ドライバー | `Layout.kt:56`, `HelpView.kt:124`, `HelpView.kt:67` |

つまり**ナビとヘルプは日本語、遷移先の画面は英語**という不一致が起きている。

---

## 2. 目的

1. データソース一覧で行内ボタンが常に見える状態にし、ページ全体の横スクロールを無くす
2. データソース / ドライバー画面のユーザー向け文言を日本語に統一し、ナビ・ヘルプの呼称と一致させる

---

## 3. スコープ

### 3.1 今回実装する

| ID | 機能 | 対応する課題 |
|---|---|---|
| F-1 | 長い接続文字列セルを省略表示 (`…`) にし、`title` 属性で全文をホバー参照できるようにする | A |
| F-2 | 操作列を `white-space: nowrap` にし、ボタンが折り返さないようにする | A |
| F-3 | テーブルを横スクロール可能なラッパーで包み、狭い画面でもページ全体ではなくテーブル内だけがスクロールするようにする | A |
| F-4 | データソース画面の見出し・列名・入力ラベル・ページタイトルを日本語化 | B |
| F-5 | ドライバー画面の見出し・列名・入力ラベル・ページタイトルを日本語化 | B |
| F-6 | ドライバー一覧の `h2` からパスを外し、配置先は補助テキストとして下に出す | P-1 |
| F-7 | ライセンスバッジの `●` `○` を削除し、ラベルを日本語化 | P-2 |
| F-8 | `.status-badge.unknown` のスタイルを追加 | P-3 |
| F-9 | 接続プロパティのカテゴリ見出しを日本語表示に変換する（ソートキーは生値のまま） | P-4 |
| F-10 | 機微情報バッジのラベルを日本語化 | P-5 |
| F-11 | ラベル変更に追随して E2E テストのセレクタを更新 | — |

### 3.2 今回実装しない (スコープ外)

| 項目 | 理由 |
|---|---|
| ドライバークラス名・JDBC URL・`TRIAL` などの識別子の翻訳 | 技術的識別子であり、翻訳すると設定値と一致しなくなる |
| CData ドライバが返すプロパティ名 (`propertyName`) と説明文 (`shortDescription`) の翻訳 | `sys_connection_props` の戻り値。翻訳辞書の新設が必要で、ドライバー更新への追従コストが高い。カテゴリ見出し (F-9) のみ固定の 4 種なので対応する |
| データソース一覧の空状態を `.empty-state` に揃える | 見た目の改善だが本件の 2 課題とは独立。`TablesView` と同形にする作業として別途 |
| `/connections/{name}` が編集フォームを返している点の見直し | 詳細表示専用ビューの新設は機能追加。現状は全文 URL の参照先として機能しているため本件では触らない |
| ページネーション / 検索 | `.steering/20260929-table-list-pagination-search/` の担当範囲 |
| 全テーブルへのレスポンシブ対応（モバイルでのカード化など） | 横スクロールで用は足りる。カード化は表示形式の変更で影響範囲が広い |
| detekt の既存違反 90 件 | Issue #9 と同様に別作業 |

## 4. ユーザーストーリー

| ID | ストーリー |
|---|---|
| US-1 | デモ環境を構築する担当者として、データソース一覧から「接続テスト」「編集」をすぐ押したい。現状はボタンが画面右外 3277px の位置にあり、横スクロールしないと押せないため |
| US-2 | デモ環境を構築する担当者として、一覧で接続文字列の頭だけでも確認したい。どのデータソースか判別できれば十分で、全文は詳細画面で見られればよいため |
| US-3 | デモを見せる担当者として、画面の文言が日本語で統一されていてほしい。ナビは「データソース」なのに遷移先の見出しが「JDBC Connections」だと、同じ画面か迷わせるため |
| US-4 | ドライバーを追加する担当者として、一覧の見出しが長い絶対パスで 2 行に折り返さないでほしい。画面の先頭が読みづらくなるため |
| US-5 | ドライバーを追加する担当者として、ライセンス状態が日本語で分かるようにしたい。`○Not activated` は記号が重複していて読みにくいため |
